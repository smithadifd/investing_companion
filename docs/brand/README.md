# Brand mark

`mark.svg` is the investing companion mark: a porthole with one line that rises and falls
inside it. It is a window you watch the market through. The line moves without promising a
direction, so it ends about where it began.

- Accent token: `ic-blue`, `#3B82F6`. It is the only colour in the mark: the rim at 50 percent
  opacity, the line at full strength, and a faint radial glow inside the circle.
- Base: `neutral-base`, `#0A0A0A`, the app's dark background. The SVG itself is transparent.
- No handle. With a handle the circle becomes a magnifying glass, which reads as search.
- Blue rather than green, because green already means gain inside the app.

Checked at 16, 32 and 128 px on `#0A0A0A` and on white. It reads at 16 px on both.

Drawn by hand as SVG; no image model was used.
